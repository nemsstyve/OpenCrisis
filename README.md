# OpenCrisis
« En échouant à se préparer, on se prépare à échouer. » — Benjamin Franklin

## Description
OpenCrisis est une plateforme dédiée à la gestion de crise, avec un focus particulier sur les incidents cyber.

Elle centralise les informations et les outils essentiels au pilotage d’une crise, afin de faciliter la coordination, la prise de décision et le suivi des actions.

L’outil met à disposition des fonctionnalités clés telles qu’un annuaire de contacts, la gestion des plans de continuité et de reprise d’activité (PCA / PRA), ainsi que des espaces de travail collaboratifs adaptés aux cellules décisionnelles et opérationnelles.

OpenCrisis vise à offrir un cadre structuré, sécurisé et facilement accessible pour faire face efficacement aux situations de crise, de la préparation jusqu’au retour à la normale.

## Stratégie de développement
Pour la stratégie des développements, nous adoptons le modèle Git Flow.

Nous utilisons différentes branches :
- **main** : contient le code stable et déployable.
- **dev** : contient le code en cours de développement.
- **dev-nom_de_la_feature** : branches dédiées à une nouvelle fonctionnalité.
